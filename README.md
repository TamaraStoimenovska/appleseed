A responsive landing page built using Next.js and Tailwind CSS, featuring a clean UI, reusable components, and optimized performance for mobile and desktop users.


## Installation
    
```bash
    npm install
```
    
or
    
```bash
    yarn install
 ```


You can start the project on the local server
    
```bash
    npm run dev
 ```

It’ll start the template on [localhost:3000](http://localhost:3000).
